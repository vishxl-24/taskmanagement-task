# AI Usage Summary

This document provides a transparent summary of the AI tools, prompts, and manual code reviews used during the development of this Task Management application for the Graduate Support Engineer Trainee placement assessment.

## AI Tools Used

- **Google Antigravity** (Powered by Gemini 3.6 Flash)

## How AI Was Used

AI assistance was utilized across the software development lifecycle to accelerate project completion within the 2.5-hour assessment timeframe:

1. **Project Scaffolding**: Initial Vite + React template setup, directory structure organization, and npm dependency configuration.
2. **Implementation Suggestions**: Structuring service abstractions (`authService.js`, `taskService.js`) and React state handling.
3. **Firebase Integration Assistance**: Setting up Firebase Auth (`signInWithPopup`), Firestore real-time queries (`onSnapshot`), and Firestore security rules.
4. **UI Implementation**: Crafting accessible HTML markup, plain CSS custom properties, responsive grid layouts, status badge design tokens, and loading state animations.
5. **Debugging & Optimization**: Diagnosing CLI command syntax differences (Windows PowerShell vs Bash), fixing Vite build scripts, and handling edge cases like empty titles and network errors.
6. **Documentation**: Drafting comprehensive `README.md`, `DEPLOYMENT.md`, and `AI_USAGE.md` files.

## Representative Example Prompts

Here are representative prompts used during development:

1. *"Build a simple React task management application using Firebase Google Authentication and Firestore with Vite and Plain CSS."*
2. *"Implement Firestore security rules so authenticated users can only create, read, and update their own tasks matching request.auth.uid, with status validation."*
3. *"Review task creation flow for validation, character limits, and duplicate submission prevention."*
4. *"Create a responsive dashboard layout in plain CSS with summary count cards for Planned, In Progress, and Complete tasks."*

## Manual Review and Modifications

All code generated by AI was thoroughly reviewed, verified, and manually refined to ensure correctness, security, and quality:

- **Adjusted Firebase Configuration**: Implemented fallback checks and diagnostic warning banners in `config.js` to ensure the application builds cleanly even before user environment variables are set.
- **Corrected Firestore Rules**: Enforced title length constraints (`size() <= 100`) and restricted allowed status values strictly to `['Planned', 'In Progress', 'Complete']` in `firestore.rules`.
- **Enhanced Validation**: Added string trimming and character count limits to `TaskForm.jsx` and `taskService.js`.
- **Improved Error Handling**: Mapped specific Firebase error codes (such as `auth/popup-closed-by-user`, `auth/unauthorized-domain`) to clear, user-friendly error banners.
- **Refined UI & Accessibility**: Replaced generic styling with custom HSL color tokens, focus rings, hover states, ARIA labels, and responsive mobile layout breakpoints in `App.css`.
- **Tested & Verified Build**: Verified `npm run build` execution to confirm zero bundler warnings or syntax errors.
